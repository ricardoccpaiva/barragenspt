O barragens.pt está mais capaz.

Esta release reúne contas de utilizador, acesso aos dados base, relatórios semanais, alertas configuráveis, API documentada e visibilidade sobre a atualização dos dados.

Registo e login de utilizadores

O barragens.pt passa a ter uma área autenticada de forma a concentrar este novo conjunto de funcionalidades.

  • Criação de conta e início de sessão no dashboard.
  • Possibilidade de alterar a foto de perfil.
  • Gestão dos canais de notificação.

Visualizar e exportar dados base

A nova área de dados permite consultar medições hidrométricas em bruto, explorar séries temporais e exportar resultados para análise externa.

  • Filtros por bacia, barragem, parâmetro e intervalo temporal.
  • Gráficos para inspecionar tendências e variações.
  • Exportação em CSV.

Um snapshot visual da semana

O relatório semanal usa os dados da segunda-feira da semana corrente para mostrar o estado do armazenamento por bacia e por barragem.

  • Mapa real das bacias com cores por estado de armazenamento.
  • Comparação com a semana anterior e média histórica de referência.
  • Detalhe por bacia, barragem, volume estimado e variação.

Alertas configuráveis por albufeira

Agora é possível acompanhar automaticamente valores críticos e receber notificações quando os dados cruzarem os critérios definidos.

  • Critérios configuráveis para diversos parâmetros.
  • Histórico para perceber quando e porquê cada alerta disparou.
  • Canais de notificação configuráveis: E-mail ou Telegram.

Acesso à API e documentação

A nova área de API torna os dados do barragens.pt mais fáceis de integrar em dashboards, automatismos e ferramentas externas.

  • Geração e gestão de tokens de acesso.
  • Documentação com endpoints, parâmetros e exemplos.
  • Controlo de utilização para acompanhar integrações.

Estado de atualização dos dados

A página de estado dá visibilidade ao funcionamento dos processos que recolhem e atualizam os dados hidrométricos.

  • Consulta do estado dos workers de atualização.
  • Mais transparência sobre a frescura dos dados disponíveis.
  • Ajuda no diagnóstico quando uma fonte externa falha ou atrasa.
